# shared

Code shared between plugins, so the math is the same in every format.

| Folder | Contents |
| --- | --- |
| `dctl/` | Includable DCTL snippets (`#include "../../shared/dctl/ease.h"`) |
| `cpp/` | OFX helpers (parameter definitions, image access) |
| `wgsl/` | WGSL functions for FilmCraft |
